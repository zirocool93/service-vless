# Ubuntu VPN Gateway

Панель управления исходящими VPN-соединениями Ubuntu Server. Сейчас реализован только **Phase 0**: Go HTTP-сервер, встроенный интерфейс React, диагностические API и контракты будущих провайдеров. VPN, изменение маршрутов, база данных, вход пользователя, HTTPS и установщик ещё не реализованы. Текущий сервер предназначен для локальной разработки.

Начало работы: [разработка](docs/development.md), [установка и текущее состояние](docs/install.md), [безопасность](docs/security.md), [сеть](docs/networking.md), [план](docs/implementation-plan.md), [архитектура](docs/architecture.md), [карта репозитория](docs/repository-map.md), [журнал](docs/work-log.md).
