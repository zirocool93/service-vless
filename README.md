# Ubuntu VPN Gateway

Панель управления исходящими VPN-соединениями Ubuntu Server. Реализованы HTTPS, вход администратора, SQLite с шифрованием секретов, импорт VLESS и подписок, управление Xray, локальные SOCKS5/HTTP-прокси и русский интерфейс с событиями SSE. Реальное проксирование проверено на тестовой Ubuntu: выходной IP меняется через VPN.

Full Tunnel, независимый сетевой watchdog, автоматическое резервирование и подключение AmneziaWG пока не прошли реализацию и приёмку. Импорт конфигурации AWG поддерживается, подключение явно недоступно. Текущее подключение VLESS обслуживает приложения, использующие локальный прокси; системный маршрут остаётся прежним.
