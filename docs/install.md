# Установка и запуск

Готового установщика пока нет. Phase 8 предусматривает идемпотентные install/update/uninstall, systemd, создание учётной записи, HTTPS и восстановление сети при удалении. До его завершения можно собрать и запустить только локальный сервер разработки по [инструкции](development.md).

Сборка на Ubuntu: установите Go 1.24+ (CI проверяет 1.26/1.27), Node.js/npm и GNU Make, затем выполните `make build` и `./bin/gateway serve`. Откройте `http://127.0.0.1:8443/` на той же машине. Это не production-сервис; туннель и системные настройки он не создаёт. Путь установки `/usr/local/bin/ubuntu-vpn-gateway` и каталоги `/var/lib/ubuntu-vpn-gateway/`, `/etc/ubuntu-vpn-gateway/` пока только проектируются.
