- До написания Full Tunnel кода создать `docs/networking-design.md` и провести отдельный review.

# 2026-10-05 — продолжение до работающего VLESS-прокси

- Добавлены SQLite и миграция, AES-GCM с привязкой секретов к записи, Argon2id, HTTPS, сессии и CSRF. Потерянный ключ при существующей БД не заменяется молча новым. CLI init создаёт администратора и выводит пароль отдельно от запуска сервиса.
- Добавлены VLESS RAW/XHTTP, REALITY/TLS, импорт подписок, атомарное сохранение узлов, избранное, проверки и управление Xray. При неудачном переключении сервис пытается восстановить предыдущий узел. AWG пока импортируется без подключения.
- Реализован русский React UI: вход, узлы, подписки, действия с подключением и SSE. Неизвестные метрики не заменяются выдуманными значениями. Проверки frontend: lint, typecheck, четыре теста, build и npm audit без уязвимостей.
- После capacity-ошибок агента протоколов код проверен и интегрирован основным агентом и core_finish. Go test по cmd/internal/web и vet прошли; govulncheck не обнаружил вызываемых уязвимых функций. Linux amd64 собран без CGO.
- На предоставленной Ubuntu 24.04 в LXC выполнены HTTPS login/import/test/connect. Два из трёх внешних узлов работают. Независимые SOCKS5 и HTTP запросы показали VPN IP 80.71.226.108 вместо прямого 194.186.91.130. SSH сохранён; системная маршрутизация не изменялась. Подробности и ограничения в test-environment.md.

Добавлена предварительная проверка кандидата при живом прежнем процессе и независимый bounded rollback после переключения; два теста проверяют сохранение прежнего узла и восстановление после отмены запроса.
