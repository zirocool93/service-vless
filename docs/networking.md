# Сетевые функции

В Phase 0 сервер не запускает Xray/AmneziaWG, не меняет маршруты, DNS, firewall и состояние сетевых интерфейсов. `/api/v1/status` пока возвращает фиксированное `disconnected`; это не результат проверки туннеля.

Full Tunnel относится к Phase 5, Safe Apply и независимый watchdog — к Phase 6. До сетевого кода необходим отдельный review [проекта сетевого управления](networking-design.md). Сейчас этот файл — чеклист для review, решение о packet flow, таблицах и правилах ещё не утверждено.

Любое изменение default route, включая конфигурацию AWG с соответствующими AllowedIPs, требует сохранённого и синхронизированного snapshot, после которого независимый watchdog вооружается и подтверждается **до первой сетевой мутации**. Проверки должны сохранять доступ SSH и панели, учитывать IPv4/IPv6, DNS и путь до VPN endpoint. Отказ должен автоматически восстанавливать прежнюю сеть. Приёмка возможна только в изолированных Linux namespaces и Ubuntu VM с проверкой аварийного отката, в том числе после падения backend. Подробнее — [план](implementation-plan.md) и [архитектура](architecture.md).
