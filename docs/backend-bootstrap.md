# Начальная настройка backend для Phase0

Phase0 добавляет HTTP-сервер на Go 1.24 и стандартной библиотеке. Команда
`gateway serve` по умолчанию слушает `127.0.0.1:8443`. Параметр
`--listen host:port` проверяется при запуске. Параметр `--max-concurrent`
задаёт предел одновременных проверок от 1 до 32 и по умолчанию равен 5.
Пока это только настройка: проверки не запускают подключения.

Сервер предоставляет `GET /api/v1/health` и `GET /api/v1/status`. Статус
честно сообщает `disconnected` и пояснение на русском языке, без фиктивных
метрик. Неизвестные маршруты `/api/` отвечают кодом 404. Файлы интерфейса
встраиваются из `web/dist`. Маршруты клиентского приложения без расширения
возвращают `index.html`; отсутствующие файлы ресурсов отвечают кодом 404.

Контракт будущего адаптера провайдера находится в `internal/provider.Provider`
и включает методы Connect, Disconnect, Status и Test. Connect и Test принимают
идентификатор; Disconnect и Status относятся к единственному активному
подключению. Состояния: disconnected, connecting, connected, disconnecting,
testing, switching, failed и rolling_back. `TestResult` описывает проверки
service, endpoint, internet и exit IP.

Phase0 не реализует и не вызывает провайдер, shell-команды, привилегированные
операции или сетевые действия. При запуске сервер предупреждает, что режим
разработки работает по HTTP без TLS и аутентификации; HTTPS и аутентификация
для production запланированы на Phase1.

Сборка интерфейса должна помещать результат в `web/dist`. Каталог `.tools/`
исключён из Git и предназначен для локального Go runtime.
