# Интерфейс Phase 0

В `web/src/App.tsx` создано русскоязычное приложение React с навигацией по будущим разделам шлюза. Главный экран показывает ответ `GET /api/v1/status` и явно обозначает, что VPN, авторизация, журнал, подписки и управление маршрутами пока не работают. Остальные разделы — информационные заглушки с перечислением отсутствующих функций; клики по навигации не вызывают сетевых изменений.

`web/src/styles.css` содержит адаптивную компоновку для настольного и мобильного экранов. На узком экране меню открывается поверх содержимого и закрывается после выбора раздела. `web/vite.config.ts` проксирует `/api` на локальный Go-сервер для режима разработки. Для этой связки сначала запустите `gateway serve`, затем `npm run dev` в `web/`. Собранная версия обслуживается Go из `web/dist` через `embed`.

Источник статуса — единственный запрос `/api/v1/status` при загрузке. При ошибке интерфейс показывает отсутствие ответа API. Поля версии и времени не изображаются, потому что endpoint их не возвращает. Сообщение `disconnected` означает текущую заглушку backend и не подтверждает реальную проверку туннеля. Проверки lint/typecheck/build выполняются командами из [инструкции разработчика](development.md); результаты конкретного запуска фиксируются в [журнале](work-log.md).
