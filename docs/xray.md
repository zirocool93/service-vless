# Жизненный цикл Xray

Xray запускается без shell-интерполяции из абсолютного пути. Временная конфигурация имеет права `0600`, сначала проверяется командой Xray `run -test`, а затем удаляется после завершения процесса. SOCKS5 и HTTP proxy слушают только `127.0.0.1`.

## Подключение и безопасное переключение

Первое подключение запускает Xray на рабочих портах после проверки кандидата. При переключении уже активного узла порядок строже:

1. новый кандидат запускается на двух случайных временных портах;
2. через его SOCKS выполняются проверка internet и получение exit IP, пока старый процесс продолжает обслуживать рабочие порты;
3. при отказе кандидат завершается, старый процесс и статус сохраняются;
4. только успешный кандидат разрешает остановить старый процесс;
5. новый узел запускается и повторно проверяется на фиксированных рабочих портах;
6. при ошибке после остановки старого узла прежняя конфигурация восстанавливается с новым bounded background context, который не зависит от отмены HTTP-запроса;
7. статус `connected` публикуется только после проверки живого процесса на рабочих портах.

Контекст запроса соблюдается до остановки старого процесса. После начала swap восстановление ограничено собственным таймаутом 35 секунд. Ответы об ошибках называют безопасную стадию (`запуск кандидата`, `проверка кандидата`, `запуск/проверка рабочих портов`, rollback) и нормализованную причину; URI, UUID, endpoint и stderr Xray наружу не передаются.

Тесты жизненного цикла используют внедряемые функции запуска и probe. Они проверяют сохранение старого процесса при отказе кандидата и восстановление старого узла после отмены request context уже внутри swap.

## Проверка узла

Одиночная проверка использует временные SOCKS/HTTP-порты и отдельный Xray process, проверяет HTTPS connectivity и внешний IP, после чего сохраняет latency, время и безопасную ошибку. Общий лимит параллелизма задаётся от 1 до 5, значение по умолчанию — 5. Проверка процесса сама по себе не считается доказательством доступа в internet.

Full Tunnel/TPROXY этим lifecycle пока не включается и сетевые маршруты, DNS или nftables не изменяются.
