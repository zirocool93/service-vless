# Безопасность текущего этапа

Phase 0 запускает обычный HTTP без TLS, аутентификации и управления VPN. По умолчанию сервер привязан к `127.0.0.1:8443`; используйте его только для локальной разработки. Параметр `--listen` может изменить адрес, поэтому не задавайте внешний адрес на открытом сервере. Ответ `health` подтверждает работу HTTP-приложения, а не наличие безопасного туннеля.

В Phase 1 запланированы HTTPS, локальный администратор, Argon2id, защищённые сессии, CSRF и ограничения частоты. Последующие фазы должны защищать секреты конфигураций и подписок, разделять сетевые привилегии и выполнять Safe Apply с независимым watchdog. Требования и критерии приёмки приведены в [плане](implementation-plan.md) и [архитектуре](architecture.md). До этих проверок продукт не готов к production-развёртыванию.
